# D5：Codex 原生交互

状态：`beta.4` 闭环已完成
优先级：P0
日期：2026-07-16

## 1. 产品目标

把 Codex turn 中必须由人处理的选择、追问和权限请求安全映射到飞书，并让模型与推理设置遵循本机 Codex 的真实能力。用户无需猜测某个按钮是否生效，也不会因为 Codex 版本或模型目录变化而让任务直接崩溃。

## 2. 已确认决策

- 模型、推理强度和任务权限按飞书会话保存；群聊按成员隔离时，每位成员拥有独立设置。
- 设置只作用于下一轮任务，已经运行的 turn 不在中途更换模型或权限。
- “Codex 默认”是动态默认语义，不固定到今天的默认模型；即使部署者设置了全局模型，会话仍可显式恢复 Codex 原生默认。
- 模型目录可用时，只显示目标模型真实支持的推理强度；已保存模型消失或推理强度失效时，本任务安全回退并明确提示。
- 模型目录暂时不可用时进入只读兼容模式，不猜测模型能力、不覆盖用户已有设置，任务仍使用当前可验证配置尝试执行。
- 运行时审批默认主操作为“允许一次”；“本会话允许”是次级操作并再次确认，其作用域由 Codex 原生协议决定。
- 问题、审批、任务、飞书会话和发起人绑定；每个请求只能消费一次，并在到期、停止或会话重置时进入终态。
- 密码、令牌、密钥等 `isSecret` 问题不接受任何飞书答案，也不进入本地提示词、任务记录或内容日志。用户只能取消远程回答后回到可信本机处理。
- 完全访问可以自动允许普通本地命令，但不会绕过 commit、push、deploy、publish、release 和 PR/MR 等外部动作确认，也不会放开凭据修改、代表用户联系他人或删除外部数据。
- Token 用量只在任务完成后展示真实输入、缓存、输出和推理用量。账户额度通过 Codex `account/rateLimits/read` 原生读取，按独立 limit bucket 展示真实剩余比例、窗口与重置时间；读取失败时不以累计 token 推测额度，也不提供预计完成时间。

## 3. 交互状态机

```text
Codex 发出审批
  → pending
  → accepted_once | accepted_session | declined | expired

Codex 发出普通问题
  → pending
  → answered | cancelled | expired

Codex 发出敏感问题
  → pending（不提供答案入口）
  → cancelled | expired
```

终态卡不再包含可重复触发的操作。过期卡统一引导发送“任务”查看权威状态；伪造、跨聊天、跨成员和重复操作会被拒绝并写入审计。

## 4. 核心流程

### 模型与推理

1. 控制中心通过 Codex `model/list` 获取模型目录和每个模型支持的推理强度。
2. “Codex 默认”与显式固定某个模型分别保存，避免默认模型升级后会话仍被旧版本锁定。
3. 新任务入队前再次核对能力；模型已移除时回退到原生默认，推理强度失效时回退到该模型默认值。
4. 能力目录不可用时控制中心不展示可编辑的猜测选项，而是标记“兼容模式”。
5. 任务卡记录本次实际采用的模型、推理、权限和 thread；运行中修改控制中心不会改变当前任务快照。

### 运行时审批

1. 先经过用户、聊天、项目、角色和外部动作策略，再接收 Codex 原生请求。
2. 卡片展示请求类型、命令或文件影响、工作目录、原因、项目和作用域语义。
3. 允许一次是默认动作；会话允许需要二次确认；拒绝和超时都返回 Codex 原生拒绝结果。
4. 请求从待处理映射中原子删除后才恢复 turn，阻止双击、重放或多人同时消费。
5. 成功、拒绝、过期和越权尝试都记录操作者、任务、结果与范围，不记录完整提示词或秘密。

### 结构化问题

1. 三个以内选项使用快捷按钮，更多选项使用下拉框，自由回答可直接发送下一条消息。
2. 同一成员会话同一时刻只接受一个待回答问题；新问题到来时旧问题安全过期。
3. 空答案、问题 ID 不匹配和旧卡操作不会误将问题标记为已回答。
4. `isSecret` 问题只展示风险说明和“取消回答”，任何文字或伪造卡片答案都会被拦截和脱敏审计。

## 5. 验收标准

- 飞书答案准确恢复对应 Codex turn，而不是创建新任务。
- 同一审批或问题至多被消费一次；重复点击只得到失效提示。
- 成员不能处理其他成员或其他聊天的交互；管理员接管仍产生审计。
- 每张审批卡说明请求类型、项目、影响、目录、有效期和授权范围。
- 敏感问题卡没有答案按钮、下拉框或文字转发路径，开启内容日志时同样只写脱敏占位符。
- 控制中心的推理选项是当前模型支持集合的子集，不显示内部枚举值作为用户文案。
- 删除已保存模型或移除推理档位不会使任务崩溃；用户能看到回退原因。
- 模型目录不可用时设置卡可正常打开，并明确处于兼容模式。
- 会话能够显式覆盖部署级固定模型并恢复 Codex 原生默认。
- 设备与模型控制中心能显示 Codex 返回的各独立额度窗口；额度不可用时不显示伪造百分比。
- 过期、停止和重置会关闭所有待处理交互，卡片不残留可执行按钮。

## 7. 非目标

- 通过飞书收集密码、验证码、令牌、私钥或其他秘密。
- 在运行中的 turn 中途热切换模型、推理或 sandbox。
- 自行实现与 Codex app-server 不兼容的审批或问题协议。
- 根据累计 token 预测模型额度、价格或任务完成时间；只展示 Codex 原生返回的账户额度。
- 在 beta.4 中实现本机安全输入代理；敏感输入需要回到可信本机完成。
